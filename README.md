# FernandezJavierEjercicio1
Caso práctico: Lotería de navidad


Descripción:
Proyecto desarrollado en Java que simula un sorteo de la Lotería de Navidad.
Programa:
- Genera aleatoriamente los numeros de los boletos.
- Permite al usuario introducir su número de décimo.
- Permite indicar el numero de importes jugados.
- Comprueba si el número coincide con algún premio.
- Calcula automáticamente la cantidad ganada.

Funcionamiento:
1. Se generan números aleatorios entre 1 y 99999.
2. El usuario introduce su número de décimo.
3. El usuario introduce el importe jugado.
4. El programa valida los datos introducidos.
5. Se comprueba si el número coincide con algún premio.
6. Se muestra el resultado por pantalla.

Tecnologías utilizadas:
- Java
- IntelliJ IDEA
- Git
- GitHub
